# Mahwar — Smart City Operations Dashboard

**Hackathon Project | Ibdaathon Qassim 2026 | Smart Cities & Robotics Track**

## Project Overview

Mahwar is a smart-city project developed to explore how technology can support traffic management, emergency response, and public safety through a unified operational dashboard.

Our project combines a web-based interface with an Arduino-based component to demonstrate how software and hardware can contribute to a smart-city solution. The dashboard presents traffic information, emergency-response scenarios, traffic-signal recommendations, suspicious-activity alerts, and operational insights in one place.

Our goal is to explore how centralized information, interactive visualization, and hardware-based components could support situational awareness and improve coordination in urban environments.

## Project Objectives

- Present traffic conditions and operational information through a unified dashboard.
- Demonstrate potential emergency-response workflows and traffic-coordination scenarios.
- Explore traffic-signal recommendations and green-corridor concepts for emergency vehicles.
- Display example alerts and operational insights.
- Combine web technologies and Arduino-based development within a smart-city project.

## Features Demonstrated

### 1. Smart City Dashboard
A multi-section interface that brings together traffic metrics, alerts, emergency scenarios, and operational insights.

### 2. Traffic Management
Displays example traffic metrics and visual representations of traffic conditions using simulated data.

### 3. Emergency Response
Demonstrates an emergency-vehicle request workflow with simulated dispatch and route-related messages.

### 4. Traffic-Signal Recommendations
Presents example traffic-management actions and green-corridor concepts for emergency-response scenarios.

### 5. Alerts and Operational Insights
Displays predefined examples of suspicious-activity alerts and summarized operational information.

### 6. Interactive Map
Uses Leaflet and OpenStreetMap to display geographic information and predefined demonstration markers.

### 7. Arduino-Based Component
Includes an Arduino-based hardware component as part of the project's smart-city concept, complementing the software dashboard.

## Prototype Notice

Mahwar is a hackathon prototype designed to demonstrate a potential smart-city solution. The web dashboard currently uses simulated values, predefined examples, and demonstration logic.

The dashboard does not connect to live traffic feeds, public-safety systems, or real traffic-signal infrastructure. Emergency dispatch messages and green-corridor scenarios displayed in the interface are simulated and do not trigger real-world actions.

The Arduino component forms part of the project prototype. The specific hardware functionality depends on the implemented demonstration. Mahwar is not a production-ready traffic-management or emergency-dispatch system.
