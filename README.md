# Mahwar — Smart City Operations Dashboard

**Hackathon Project | Ibdaathon Qassim 2026 | Smart Cities & Robotics Track**

## Project Overview

Mahwar is a smart-city project concept developed to explore how traffic management, emergency response, traffic-signal recommendations, suspicious-activity alerts, and operational insights could be presented through a unified dashboard.

The project aims to demonstrate how a centralized interface could help city operators view different types of urban information, monitor simulated events, and explore potential responses to traffic and emergency scenarios.

Developed as part of Ibdaathon Qassim 2026 in the Smart Cities & Robotics track, Mahwar combines a web-based dashboard prototype with a smart-city concept focused on traffic coordination and emergency-response support.

## Project Objectives

- Present traffic conditions and operational metrics in a centralized interface.
- Demonstrate emergency-response workflows and example vehicle requests.
- Display traffic-signal recommendations and suggested traffic-management actions.
- Provide example alerts for suspicious activities and other operational events.
- Explore how data visualization could support situational awareness and decision-making in smart cities.

## Features Demonstrated

### 1. Smart City Operations Dashboard
A multi-section interface that brings together traffic information, alerts, emergency scenarios, and operational insights.

### 2. Traffic Management
Displays example traffic metrics, vehicle counts, speed indicators, occupancy values, and visual representations of traffic conditions.

### 3. Emergency Response
Includes an emergency-vehicle request interface that demonstrates a simulated dispatch status and route-related message.

### 4. Traffic-Signal Recommendations
Presents example traffic-management actions and green-corridor concepts intended to illustrate how emergency routes might be prioritized.

### 5. Suspicious-Activity Alerts
Displays example alerts to demonstrate how potentially important events could be presented to city operators.

### 6. Interactive Map
Uses Leaflet with OpenStreetMap tiles to display a map and predefined demonstration markers.

### 7. Operational Insights
Includes an insights section with example indicators and visual elements to demonstrate how operational information could be summarized in one interface.

## Technologies Used

- **HTML** — Page structure and dashboard components
- **CSS** — Layout, styling, and visual presentation
- **JavaScript** — Interface interactions and demonstration logic
- **Leaflet** — Interactive map functionality
- **OpenStreetMap** — Map tiles and geographic visualization

Leaflet and OpenStreetMap resources are loaded online, so an internet connection is required for the map to display correctly.

## Prototype Notice

Mahwar is a hackathon prototype intended to demonstrate a smart-city dashboard concept. The current web interface uses simulated data, predefined examples, and demonstration logic.

It does not connect to live traffic feeds, public-safety systems, a verified AI inference service, or real traffic-signal infrastructure. The displayed metrics, alerts, confidence scores, and estimated arrival times are illustrative. Emergency dispatch messages and green-corridor scenarios are simulated and do not trigger real-world actions.

The prototype demonstrates a potential interface and workflow rather than a production-ready smart-city management system.

## How to Run the Project

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Ensure an internet connection is available for the map library and map tiles.

No backend server is required for the current front-end demonstration.
