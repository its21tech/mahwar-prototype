# Mahwar — Project Overview

## 1. Introduction

Mahwar is a smart-city project developed for Ibdaathon Qassim 2026 under the Smart Cities & Robotics track. The project explores how technology can support traffic management, emergency response, and public safety through a unified operational concept.

The project includes two web interfaces that demonstrate different aspects of the proposed smart-city solution.

## 2. Project Objectives

The main objectives of Mahwar are to:

- Present traffic and operational information through a unified interface.
- Demonstrate emergency-response scenarios.
- Explore green-corridor concepts for emergency vehicles.
- Visualize traffic conditions and possible route changes.
- Explore how software and hardware can contribute to smart-city applications.

## 3. Web Interfaces

### 3.1 Smart City Operations Dashboard

The first interface presents a dashboard that brings together traffic indicators, emergency-related information, alerts, operational insights, and an interactive map.

It uses simulated data and predefined demonstration markers to illustrate how smart-city information could be presented in a centralized interface.

### 3.2 Traffic and Emergency Simulation

The second interface provides a visual simulation of traffic movement and emergency scenarios.

It demonstrates stages such as normal traffic conditions, accident scenarios, analysis, emergency response, green-corridor activation, route diversion, public warnings, and a simulation summary.

The interface uses HTML Canvas and JavaScript to draw and animate the simulated city environment.

## 4. Technologies Used

- **HTML:** Structures the web interfaces.
- **CSS:** Defines layouts, styling, and visual presentation.
- **JavaScript:** Implements interactions and simulation behavior.
- **Leaflet:** Provides interactive map functionality in the first interface.
- **OpenStreetMap:** Supplies map tiles for the first interface.
- **Arduino:** Relevant to the project's hardware component, where applicable to the implemented prototype.

## 5. Prototype Limitations

Mahwar is a hackathon prototype intended to demonstrate a smart-city concept.

The web interfaces use simulated values, predefined examples, or demonstration logic. They should not be interpreted as evidence of a connection to live traffic feeds, actual emergency services, or real traffic-signal infrastructure.

AI-related indicators and predictions displayed in the interfaces are demonstration elements unless supported by a separately implemented and verified AI system.

The web interfaces alone do not establish that hardware is connected to the dashboard or that real-world actions are performed.

## 6. Future Improvements

Potential future improvements include:

- Integrating authorized real-time traffic data sources.
- Developing backend services for data processing and storage.
- Evaluating AI-based traffic analysis using appropriate data and testing methods.
- Improving integration between software and hardware components.
- Evaluating system reliability, security, and usability.

These items are proposed future improvements, not claims about currently implemented functionality.
